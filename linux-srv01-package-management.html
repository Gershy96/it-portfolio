Package Management & System Updates

This lab demonstrates package management and system update administration on an Ubuntu Server using the APT package management system.

Lab Objective

Perform routine package management and system maintenance on the Ubuntu server by updating package repositories, upgrading installed packages, and verifying the system update process.

Environment

  • Ubuntu Server — IT-SRV01
  • Ubuntu Server version — 24.04.4 LTS
  • Server IP — 192.168.255.134
  • Virtualization — VMware Workstation

Package Management Process

  • Updated the APT package repository information.
  • Checked for available system package updates.
  • Upgraded installed packages using APT.
  • Completed package installation and configuration.
  • Verified the system update process.
