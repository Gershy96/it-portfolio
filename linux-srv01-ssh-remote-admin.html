SSH Remote Administration

This lab demonstrates configuring and using Secure Shell (SSH) to remotely administer an Ubuntu Server from a Linux workstation.

Lab Objective

Configure SSH on the Ubuntu server and demonstrate secure remote administration from the Ubuntu workstation using an SSH connection.

Environment

  • Ubuntu Server — IT-SRV01
  • Ubuntu Workstation — IT-WS01
  • Server IP — 192.168.255.134
  • Virtualization — VMware Workstation

Implementation Process

  • Installed and configured the OpenSSH server.
  • Verified that the SSH service was running.
  • Checked the server's network configuration and IP address.
  • Established an SSH connection from IT-WS01 to IT-SRV01.
  • Verified successful remote access to the Ubuntu server.
  • Demonstrated remote administration through the SSH session.
