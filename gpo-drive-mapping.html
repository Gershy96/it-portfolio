Group Policy Drive Mapping Lab

This lab demonstrates how to use Group Policy Preferences to automatically map a network drive for users within a specific Organizational Unit (OU). Automating drive mapping ensures users receive the correct shared resources at logon without manually entering network paths, reducing Help Desk requests and improving the user experience.

Help Desk Ticket

Ticket #1046

Requester: HR Department

Issue:

Users in the HR department need the HR shared drive (\\SERVER\HR) to be automatically mapped every time they log in. Currently, users must manually map the drive each time, causing delays and unnecessary support requests.

Goal:

Configure Group Policy so the HR shared drive is automatically mapped whenever HR users sign in.

Scope:

  • Apply only to users in the HR Organizational Unit.
  • Automatically map the HR shared drive at user logon.
  • Verify successful access after policy application.

Environment

  • Windows Server 2022
  • Active Directory Domain Services
  • Group Policy Management
  • Windows 10 Client
  • HR Organizational Unit
  • Shared Folder: \\SERVER\HR

Problem

HR users were required to manually map the HR shared drive whenever they logged on. This created unnecessary Help Desk requests and slowed access to shared departmental resources.

Solution

A Group Policy Preference was configured using the Drive Maps extension within User Configuration. The policy maps the HR shared drive automatically during user logon and is linked specifically to the HR Organizational Unit, ensuring that only HR users receive the mapped drive.

Verification

After forcing a Group Policy update and signing in as an HR user, the following was verified:

  • The HR network drive appeared automatically in File Explorer.
  • No manual mapping was required.
  • The shared folder opened successfully.
  • The policy applied only to users within the HR Organizational Unit.

Commands Used

gpupdate /force

Learning Outcome
