IT Support & Service Desk

Completed Projects

1. GLPI Ticket Management & Incident Resolution

Used GLPI to simulate a real help desk incident involving an employee who could not access an HR shared drive.

Skills demonstrated:

  • Incident creation and ticket management
  • Investigating a reported user issue
  • Documenting troubleshooting actions
  • Recording the resolution and closing the ticket

Evidence: Demonstration video prepared for LinkedIn.

2. Remote Support with Remmina

Configured remote desktop access from the Ubuntu technician workstation to both Windows end-user workstations.

Skills demonstrated:

  • Connecting to remote Windows desktops
  • Authenticating with the domain technician account
  • Supporting end-user computers remotely
  • Verifying successful remote connections

3. IT Network Reference Documentation

Created a network reference document for the lab to provide technicians with essential network information during support incidents.

Documented information includes:

  • Network subnet and subnet mask
  • Default gateway and DNS server
  • Domain information
  • Device names, roles and IP addresses
  • DHCP status

The document was created in LibreOffice Writer and exported to PDF. Some device addresses were carried forward from previous configuration records rather than reverified during this session.

Upcoming Projects

4. Network Connectivity & DNS Troubleshooting

Simulate a user incident in which a Windows workstation cannot access websites because of an incorrect DNS server configuration.

Planned workflow:

  • Log the incident in GLPI
  • Investigate the workstation's network configuration
  • Identify the DNS issue using troubleshooting evidence
  • Restore the verified DNS configuration
  • Test connectivity and DNS resolution
  • Document the resolution in GLPI
