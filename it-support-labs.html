IT Support & Service Desk

This section showcases practical Level 1 IT Support and Help Desk exercises completed in a simulated corporate IT environment. The projects demonstrate incident management, remote support, network documentation and structured troubleshooting.

Lab Environment

  • Ticketing System: GLPI 11.0.11

  • End-User Systems: Windows 10 Pro workstations

Completed Projects

1. GLPI Ticket Management & Incident Resolution

This project demonstrates a simulated help desk incident involving an employee who could not access an HR shared drive. The workflow covers ticket creation, troubleshooting, corrective action, verification and documentation.

Skills demonstrated:

  • Incident creation and ticket management
  • GLPI asset inventory and user administration
  • Windows workstation troubleshooting
  • Documenting corrective actions
  • Verifying the solution and closing the ticket

View GLPI Ticket Management Project →

2. DNS Troubleshooting & Incident Resolution

This four-part case study follows a DNS incident affecting a Windows workstation. The technician uses Remmina for remote support, investigates the DNS configuration, consults the IT network reference document, corrects the configuration and verifies that website access is restored.

Skills demonstrated:

  • Incident investigation and structured troubleshooting
  • Remote support using Remmina and RDP
  • Windows DNS configuration and diagnostic checks
  • Using IT reference documentation
  • Verifying DNS resolution and website access
  • GLPI resolution documentation and ticket closure

View DNS Incident Case Study →

3. Remote Support with Remmina

Configured and used remote desktop access from the Ubuntu technician workstation to Windows end-user workstations. Remote access was also demonstrated as part of the DNS incident troubleshooting workflow.

Skills demonstrated:

  • Connecting to remote Windows desktops
  • Authenticating with a domain account
  • Supporting end-user computers remotely
  • Verifying successful remote connections

4. IT Network Reference Documentation

Created a network reference document in LibreOffice Writer and exported it to PDF to support consistent troubleshooting and provide technicians with essential network information.

Documented information includes:

  • Network subnet and subnet mask
  • Default gateway and DNS server
  • Domain information
  • Device names, roles and IP addresses
  • DHCP status

This documentation was used as a reference during the DNS troubleshooting case study.
