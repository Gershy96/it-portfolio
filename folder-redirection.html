Folder Redirection Lab

This lab demonstrates how to configure Folder Redirection through Group Policy in a Windows Server 2022 Active Directory environment. The configuration redirects a user's Documents folder from the local Windows client to a folder hosted on the domain server.

Objective

Configure a Group Policy Object to redirect the Documents folder for domain users to a server-based location, then verify that the redirection is working from the Windows client.

Environment

  • Windows Server 2022
  • Active Directory Domain Services
  • Domain: corp.local
  • Domain Controller: DC01
  • Windows client joined to the domain
  • Group Policy Management
  • Redirected folder location: \\DC01\RedirectedFolders

Configuration

Folder Redirection was configured through Group Policy. The user's Documents folder was redirected to a server-side location so that the data is stored on the Windows Server rather than only on the local workstation.

The policy was applied to the appropriate domain user and tested from the Windows client.

Verification

After applying the Group Policy configuration, I signed in as the test domain user and verified that the Documents folder was redirected successfully.

  • The Documents folder displayed the redirected network location.
  • The redirected path was \\DC01\RedirectedFolders\sjohnson.
  • A test file was created in the redirected Documents folder.
  • The corresponding user folder was visible on DC01.

This lab demonstrates the practical use of Group Policy to centrally manage user folder locations. Folder Redirection can keep user data on a server-based location, making it easier to manage and access within a Windows domain environment.
