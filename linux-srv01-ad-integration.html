Active Directory Integration

This lab demonstrates integrating an Ubuntu Server with a Windows Active Directory environment, allowing the Linux server to discover the domain and authenticate using Active Directory accounts.

Lab Objective

Join the Ubuntu server to the corp.local Active Directory domain and configure the required services for domain discovery, identity management, and authentication.

Environment

  • Ubuntu Server — IT-SRV01
  • Windows Server 2022 — DC01
  • Active Directory domain — corp.local
  • Domain Controller IP — 192.168.255.10
  • Virtualization — VMware Workstation

Implementation Process

  • Configured the Ubuntu server for Active Directory integration.
  • Installed and configured the required AD integration packages.
  • Joined IT-SRV01 to the corp.local domain.
  • Verified successful domain membership using realm.
  • Configured and verified SSSD for domain identity management.
  • Tested Active Directory user account resolution.
  • Verified authentication using an Active Directory account.
