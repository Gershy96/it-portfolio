Active Directory Domain Join

This lab demonstrates joining an Ubuntu Linux workstation to a Windows Active Directory domain and verifying successful domain membership.

Lab Objective

Join the Ubuntu workstation to the corp.local Active Directory domain and verify that the workstation can successfully communicate with and authenticate against the domain.

Environment

  • Ubuntu Linux workstation — IT-WS01
  • Windows Server 2022 — DC01
  • Active Directory domain — corp.local
  • Virtualization — VMware Workstation

Implementation

  • Verified Active Directory domain discovery.
  • Joined the Ubuntu workstation to corp.local.
  • Verified successful domain membership.
  • Verified Active Directory user and identity information.
