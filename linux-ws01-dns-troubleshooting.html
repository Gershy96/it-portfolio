DNS Troubleshooting & Domain Discovery

This lab demonstrates troubleshooting DNS configuration and Active Directory domain discovery from an Ubuntu workstation in a virtualized Windows and Linux environment.

Lab Objective

Identify and resolve a DNS configuration issue preventing the Ubuntu workstation from discovering the corp.local Active Directory domain.

Environment

  • Ubuntu Linux workstation — IT-WS01
  • Windows Server 2022 — DC01
  • Active Directory domain — corp.local
  • Virtualization — VMware Workstation

Troubleshooting Process

  • Investigated the domain discovery failure.
  • Checked the workstation's DNS configuration.
  • Investigated DNS and Active Directory service records.
  • Corrected the DNS configuration.
  • Verified successful Active Directory domain discovery.
